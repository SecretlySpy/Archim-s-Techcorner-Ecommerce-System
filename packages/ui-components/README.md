# @archim/ui-components

Shared UI design tokens and primitives for Archim's TechCorner apps.

## Tokens
- JS: `import { tokens } from '@archim/ui-components'`
- CSS: `@import '@archim/ui-components/styles/design-tokens.css';` or link

Extracted from existing globals.css (glass-over-hardware). Authoritative in this package.

See src/tokens.ts for consts.
